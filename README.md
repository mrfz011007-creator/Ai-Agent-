# Echoes of the Forgotten

Long-term Android RPG experiment and cross-service agent workflow test.

## Current vertical slice
- Godot 4 project structure
- Top-down exploration
- Touch + keyboard movement
- NPC interaction and quest
- Inventory/potion
- Turn-based combat
- XP and level-up
- Boss encounter
- Local JSON save/load
- No external runtime dependency

## Cross-service experiment
- GitHub: source of truth and CI
- Figma: UI design source
- Replit: browser-playable prototype
- Linear: planning and execution tracking
- GitBook: documentation
- Supabase: reserved for future cloud state/telemetry; not required by the offline-first core

The Android build must remain lightweight enough for low-end hardware.
